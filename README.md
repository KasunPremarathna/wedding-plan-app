# Wedding Planner LK

A premium wedding planning application built for Sri Lankan couples. 

## 🏪 1. Vendor Discovery & Marketplace
* **Smart District Filtering:** Discover verified vendors across 10+ core categories (Hotels, Photography, Bridal, Poru Ashtaka, Deco, etc.) filtered by any Sri Lankan district.
* **Rich Vendor Profiles:** Explore high-resolution photo galleries, detailed portfolios, ratings, and genuine customer reviews.
* **Transparent Package Tiers:** View clear pricing breakdowns for Basic, Standard, and Premium packages.
* **One-Tap Direct Contact:** Instantly connect with vendors via Direct Call or WhatsApp to get custom quotes.

## 💰 2. Smart Budget Tracker
* **Total Budget Allocation:** Set your maximum budget limit and track real-time allocation with visual progress bars.
* **Categorized Expense Logging:** Easily log custom expenses under specific categories (Venue, Catering, Photography, Attire, etc.).
* **Real-time Balance Calculations:** Automatic calculations for total spent, category totals, and remaining balance.

## 👥 3. Advanced Guest List Manager
* **Group & RSVP Tracking:** Manage guest lists by groups (Bride’s Side, Groom’s Side, Friends, VIPs) with real-time status tracking (Attending, Pending, Not Attending).
* **Meal Preference Tracking:** Filter guest dietary requirements (Veg, Non-Veg, Vegan, Kids Menu).
* **Automated Food Cost Estimator:** Input hotel plate costs to automatically calculate total food expenditure based on confirmed guests.
* **Smart Liquor Cost Estimator:** Toggle liquor consumers per guest to instantly calculate predicted beverage expenses.

## 📅 4. Wedding Planning Tools
* **Interactive Timeline Checklist:** Step-by-step milestone checklist with visual completion progress bar to keep planning on track.
* **Personalized Nekath (Auspicious Times) Manager:** Dedicated section to store, structure, and display personalized wedding auspicious times (Poruwa, Departure, Homecoming, etc.).

## ⚙️ 5. Premium App Features & UX
* **Instant Bilingual Support (English & Sinhala):** Smooth animated toggle to instantly switch the entire app interface between English and Sinhala (සිංහල).
* **Adaptive Theme Engine:** Modern UI supporting both Light and Dark modes.
* **Secure Google Authentication:** Quick, one-tap onboarding via Google Sign-In.
* **Real-time Vendor Messaging:** Built-in direct chat system for real-time negotiation and inquiry management.
* **In-App Auto-Update Notification:** Automatic Play Store version checking to prompt users when a new update is released.
* **PDF Export:** Export your Budget Report and Guest List directly to a beautifully formatted PDF document (complete with an elegant watermark) for easy printing or sharing!

## 💡 Future Roadmap
* **Seat / Table Planner:** Visual feature to assign guests to reception tables.
* **Collaboration Mode (Bride & Groom Sync):** Real-time synchronization of the budget, guests, and checklist between the Bride and Groom using Firebase.
